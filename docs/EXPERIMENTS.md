# 백테스트 시험 기록

결과를 보고 설정을 고르면 과거에만 맞는 전략이 되기 쉽다. 그래서 시험마다 규칙을 먼저 정하고 기록한다.

공통 조건
- 데이터: KIS 모의투자 서버 일봉(수정주가), 2020-09 ~ 2026-10. 2026-07-31 코스피 +17.9% 같은 큰 움직임도
  뉴스와 대조해 실제 값임을 확인했다.
- 계좌 전체 백테스트: 실제 엔진을 과거 날짜마다 돌린다(`trading/backtest/portfolio.py`).
  국내 2천만원, 미국 $14,000. 수수료/세금 포함, 환율 변화 제외.
- 고르는 규칙: 앞 기간(2021~2023)의 `연수익률 ÷ |최대낙폭|`이 가장 큰 설정을 고르고,
  뒤 기간(2024-01 ~ 2026-10)에서 확인한다. 두 기간은 각각 새 계좌로 시작한다.
- 다시 돌리기: `uv run python -m trading.backtest.compare --experiment ab|cd`

## 시험 ab: 전략 배분, 남는 현금을 지수 ETF로 (2026-10-23)

뒤 기간 결과(앞 기간에서 고른 설정 ◀):

| 국내 | 연수익 | 최대낙폭 | | 미국 | 연수익 | 최대낙폭 |
|---|---|---|---|---|---|---|
| 50/50(지금) | +29.6% | -28.1% | | 50/50(지금) | +5.4% | -9.1% |
| 추세만 +ETF ◀ | +48.4% | -44.3% | | 50/50 +ETF ◀ | +17.8% | -18.8% |
| KODEX 200 | +40.6% | -41.6% | | SPY | +20.1% | -18.8% |

결론: ETF 굴리기는 수익을 지수 수준으로 올리지만 낙폭도 지수 수준이 된다. 지수 ETF를 그냥 사는 것보다
확실히 낫다고 할 수 없다. 배분 조정은 앞 기간에 차이가 거의 없어 고를 근거가 약했다.

## 시험 cd: 추세 추종 보완, 종목 확대 (2026-10-23)

미리 고정한 숫자: 고점 대비 손절 15%, 시장 필터는 지수 ETF 60일선, 종목 확대는 국내/미국 20개씩
(`config/universe_wide.toml`, 지금의 대형주라 생존 편향이 있다).

| 국내 | 앞:연수익 / 낙폭 | 뒤:연수익 / 낙폭 |
|---|---|---|
| 기준(지금) | -0.5% / -13.3% | +29.6% / -28.1% |
| C1 고점손절 | -0.7% / -13.8% | +16.0% / -13.0% |
| C2 시장필터 | -0.8% / -11.1% | +32.2% / -28.7% |
| C1+C2 | -0.8% / -11.1% | +17.9% / -12.1% |
| D 종목확대 | +1.1% / -21.9% | +21.8% / -33.1% |
| D+C1+C2 ◀ | +1.6% / -16.5% | +10.9% / -18.9% |

| 미국 | 앞:연수익 / 낙폭 | 뒤:연수익 / 낙폭 |
|---|---|---|
| 기준(지금) | -2.4% / -19.0% | +5.4% / -9.1% |
| C1 고점손절 | -1.3% / -16.2% | +6.0% / -7.7% |
| C2 시장필터 | -2.6% / -19.7% | +5.4% / -9.1% |
| C1+C2 | -1.4% / -17.1% | +6.0% / -7.7% |
| D 종목확대 ◀ | +11.3% / -12.6% | +3.5% / -13.5% |
| D+C1+C2 | +5.7% / -15.6% | +6.8% / -12.8% |

결론
- 앞 기간에서 고른 설정(두 시장 모두 종목 확대 계열)이 뒤 기간에는 기준보다 나빴다. 앞 기간이
  횡보/하락장이라 설정 간 차이가 작았고, 작은 차이로 고른 것이 맞지 않았다.
- C1(고점 대비 손절)은 뒤 기간에 두 시장 모두 낙폭을 줄였다(국내 -28%→-13%, 미국 -9%→-8%).
  국내는 수익도 절반으로 줄었다. 수익을 올리는 장치가 아니라 더 방어적으로 만드는 장치다.
  앞 기간 국내에서는 효과가 없어 확인된 개선이라고 하기는 어렵다.
- C2(시장 필터) 단독은 거의 차이가 없었고, D(종목 확대)는 뒤 기간에 나빠졌다.
- 이 두 전략을 조금씩 고치는 것으로는 지수 수준의 수익을 기대하기 어렵다.
  지금 설정의 강점은 수익보다 낙폭이 작다는 점이다.

운영 설정은 바꾸지 않았다(C1, C2는 기본값 꺼짐).
